# Contact Book

A simple contact management program written in Python.

## What it does

- Stores contacts (name and phone number)
- Saves contacts to a file so they persist between runs
- Loads saved contacts back when the program starts

## How it works

Built with two classes:
- `Contact` — represents a single contact (name, phone)
- `AddressBook` — holds a list of contacts, with methods to add, show, save, and load them

Data is saved to a JSON file and loaded back using Python's `json` module.

## How to run

​```
python contact.py
​```
